GLASSHOUSE

Every page you open can read more about your device than you might expect. GLASSHOUSE asks your browser the same questions a tracking script would, then explains each answer and stops there. Everything happens on this device.

The privacy boundary

No uploads, no analytics, no cookies set by this page, no external fonts or images, and no network requests after the page has loaded. It keeps working with the network switched off.

Inspection

Each probe below runs in this page, one at a time. Nothing leaves your device, and nothing asks you for a permission.

    What it can read
    Reports written by this build of GLASSHOUSE: report version 1, snapshot version 1, with all 14 probes present exactly once. Every figure in a file is re-derived from the probe catalog before it is shown, so a hand-edited total cannot be displayed as fact. Anything else is refused, with the reason spelled out.
    Size bound
    A file larger than 256 KiB is refused without being read. A genuine report is a few kilobytes.
    Redacted or raw
    A redacted report — the default when you save one — still gives a complete comparison of statuses, detail grades, points and category totals. Exact value changes appear only when both reports were saved with their observed values included; otherwise that is stated plainly instead of guessed at.
    Nothing is kept
    Imported reports exist in this tab's memory only. They are never written to local storage, session storage, IndexedDB or a cookie, and never sent anywhere. Clear imported reports discards them immediately.

    Echo Test: which answers hold still

    A single scan tells you what could be read. This asks a different question: read the same probes 3 sequential runs in a row, right now, and see which answers came back identical every time. Nothing new is probed, nothing extra is asked of your browser, and every run stays in this tab's memory.

    No echo test has been run.

    Stable
    At least two runs returned a reading, every reading was identical, and the outcome never changed within this experiment. This does not prove that it will stay the same after a restart, update or settings change.
    Variable
    At least two runs returned a reading and at least one differed, with no change of outcome. Some browsers vary these answers deliberately.
    Intermittent
    The outcome itself changed between runs — any transition among readable, blocked, unsupported or failing. The probe did not behave the same way each time.
    Not enough evidence
    Fewer than two runs returned a reading and the outcome never changed, so there was nothing to compare. This is the honest answer, not a zero.
    While it runs
    The status line above counts the runs as they happen — Run 1 of 3, then Run 2 of 3 — and Clear echo test stays available throughout, so you can withdraw at any moment. A run you cancel is discarded rather than finished quietly.
    Nothing is kept
    The repeated readings live in this tab's memory only. They are never written to local storage, session storage, IndexedDB or a cookie, and never sent anywhere. Reloading this page discards them.

    What this cannot tell you

    • It is not an identity check. GLASSHOUSE never claims how unique or identifiable you are, because that depends on a population it cannot see from your device.
    • The score is a breadth measure of how much this fixed probe set could read. It is not an entropy estimate, a fingerprint, or a security verdict.
    • A low score is not anonymity. Your address, your network, and anything you type are all outside what a page-local inspection can observe.
    • Some browsers deliberately return randomised or coarsened answers. That shows up here as values that change between runs, which is protection working rather than a fault.
